# IslandVolt

[![Repository checks](https://github.com/VoltCoreLabs/IslandVolt/actions/workflows/repository-checks.yml/badge.svg)](https://github.com/VoltCoreLabs/IslandVolt/actions/workflows/repository-checks.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Персональный настольный остров на **Rust + GPUI** для **Windows 10 и Windows 11**.
Компактная панель объединяет музыку, быстрые инструменты, заметки, ИИ и анимированных животных.

Репозиторий: [VoltCoreLabs/IslandVolt](https://github.com/VoltCoreLabs/IslandVolt).

**Статус: технический прототип.** Начата проверка Rust + GPUI и создано первое окно.
Совместимость с Windows 10 и 11 и поведение окна ещё предстоит подтвердить.
Окно появляется сверху основного экрана в форме пилюли и закрепляется поверх обычных окон.
Оно показывает местное время; нажатие переключает подпись между названием и датой.
Если текущий медиаплеер передаёт Windows название трека, оно появляется в острове.
При поддержке плеера кнопки рядом с часами управляют воспроизведением и переключением треков.
Кнопка динамика открывает управление общей громкостью и отключением звука устройства.
Для интерфейса используются [Phosphor Icons](assets/icons/phosphor/README.md).
Название проекта — **IslandVolt**; префикс будущих Rust-пакетов — `islandvolt-`.

Прототип собирается командой `cargo build` и запускается командой `cargo run -p islandvolt-app`.
Для сборки на Windows нужны Rust и инструменты сборки MSVC.

## Первый рабочий релиз

- Остров: компактное и раскрытое состояния, закрепление, перемещение, настройки.
- Текущая музыка и управление доступными медиасессиями.
- Общая громкость и громкость доступных аудиосессий приложений.
- Часы и один питомец, работающий через расширяемую систему пакетов.
- Светлая/тёмная тема, трей, горячие клавиши и корректное завершение.

Перед релизом нужен технический прототип окна GPUI и Windows-интеграций на обеих ОС.
Распознавание песни по звуку, караоке и сложная маршрутизация аудио идут отдельными этапами.

## Принцип расширения

Новая возможность добавляется отдельным feature-модулем с контрактами, логикой и UI.
Windows API, хранение и провайдеры подключаются через адаптеры.
Оболочка острова управляет размещением карточек и событиями, а не реализацией каждой функции.

Все созданные текстовые файлы укладываются в 300 строк.
Генерируемый Cargo.lock является исключением из ограничения по числу строк.
