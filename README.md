# IslandVolt

[![Repository checks](https://github.com/VoltCoreLabs/IslandVolt/actions/workflows/repository-checks.yml/badge.svg)](https://github.com/VoltCoreLabs/IslandVolt/actions/workflows/repository-checks.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Персональный настольный остров на **Rust + GPUI** для **Windows 10 и Windows 11**.
Компактная панель объединяет музыку, быстрые инструменты, заметки, ИИ и анимированных животных.

Репозиторий: [VoltCoreLabs/IslandVolt](https://github.com/VoltCoreLabs/IslandVolt).

**Статус: технический прототип.** Начата проверка Rust + GPUI и создано первое окно.
Совместимость с Windows 10 и 11 и поведение окна ещё предстоит подтвердить.
Остров примыкает к верхней кромке экрана: чёрный контур с вогнутыми плечами, прямым
нижним краем и округлыми углами рисуется GPUI. При наведении раскрывается сама чёрная
форма, без отдельной полупрозрачной панели и системной рамки. Вне контура окно прозрачно.
Он показывает местное время и текущую активность и закрепляется поверх обычных окон.
Внутри появился пробный кот Вольт: моргает, реагирует на клик или P и засыпает
после минуты без взаимодействия с ним. «Скрыть кота / Показать кота» сохраняется между запусками.
При скрытии острова и в меню плееров анимация приостанавливается;
при отключённых анимациях Windows показывается статичный спящий кадр.
Это первый [технический пакет питомца](assets/pets/volt-cat/README.md), стиль коллекции ещё не выбран.
Если текущий медиаплеер передаёт Windows название трека, оно появляется в острове.
В раскрытой панели можно выбрать плеер через пункт «изменить» или оставить автоматический
выбор Windows. При закрытии выбранного плеера включается автоматический режим.
При наведении панель управления музыкой и громкостью вытягивается только вниз,
сохраняя ширину и горизонтальное положение. Управление расположено по центру.
После ухода курсора остров сворачивается с задержкой 300 мс. Кнопка «Больше / Меньше» меняет ширину острова
и сохраняет выбор между запусками в `%APPDATA%/IslandVolt/settings.json`.
Для интерфейса используются [Phosphor Icons](assets/icons/phosphor/README.md).
Шрифт интерфейса — встроенный [Golos Text](assets/fonts/golos/README.md).
Раскрытую панель можно закрепить с сохранением между запусками. После клика по острову
клавиши ←/→ меняют громкость, M переключает mute, пробел управляет воспроизведением,
а Esc закрывает меню выбора плеера, затем открепляет и сворачивает панель.
Ctrl+Alt+Space раскрывает остров с фокусом, в том числе после скрытия через трей.
Повторное нажатие в активном острове сворачивает его; Esc и повторное нажатие возвращают
фокус предыдущему окну, если пользователь ещё не переключился в другое приложение.
Панель, открытая клавиатурой, удерживается без курсора. При занятой комбинации
доступны наведение и трей; в панели показывается статус недоступности горячей клавиши.
В системном трее доступно меню: показать остров, скрыть его или завершить приложение.
При обычном завершении последняя настройка ширины записывается до выхода процесса.
Название проекта — **IslandVolt**; префикс будущих Rust-пакетов — `islandvolt-`.

Прототип собирается командой `cargo build` и запускается командой `cargo run -p islandvolt-app`.
Для сборки на Windows нужны Rust и инструменты сборки MSVC.
`cargo run -p islandvolt-app -- --smoke-test` запускает видимое окно на 7 секунд,
проверяет размер рабочей области при раскрытии/сворачивании в двух ширинах и завершает приложение.
Этот сценарий нельзя запускать со скрытым окном: скрытая поверхность GPUI не перерисовывается.

## Первый рабочий релиз

- Остров: компактное и раскрытое состояния, закрепление, перемещение, настройки.
- Текущая музыка и управление доступными медиасессиями.
- Общая громкость и громкость доступных аудиосессий приложений.
- Часы и один питомец, работающий через расширяемую систему пакетов.
- Светлая/тёмная тема, трей, горячие клавиши и корректное завершение.

Перед релизом нужен технический прототип окна GPUI и Windows-интеграций на обеих ОС.
Распознавание песни по звуку, караоке и сложная маршрутизация аудио идут отдельными этапами.

## Принцип расширения

Новая возможность добавляется отдельным feature-модулем с контрактами, логикой и UI.
Windows API, хранение и провайдеры подключаются через адаптеры.
Оболочка острова управляет размещением карточек и событиями, а не реализацией каждой функции.

Все созданные текстовые файлы укладываются в 300 строк.
Генерируемый Cargo.lock является исключением из ограничения по числу строк.
