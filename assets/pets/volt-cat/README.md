# Кот Вольт — технический образец

Небольшой монохромный кот для проверки проигрывателя внутри IslandVolt.
Оригинальные векторные кадры созданы для проекта; автор — IslandVolt contributors.
Лицензия кадров и manifest: MIT, см. [основную лицензию](../../../LICENSE).
Это персонаж, а не иконка интерфейса; UI-иконки остаются Phosphor.

Пять встроенных SVG: покой, моргание, два кадра радости и сон.
Кадры используют прозрачность и вырезы, поэтому GPUI может окрашивать их одной маской.
Исходная координатная сетка — 48×48; размер в острове — 32 логических пикселя.
Моргание происходит раз в несколько секунд, после минуты без клика кот засыпает.
Клик будит его и запускает короткую реакцию. При уменьшенном движении кадр статичен.

Пакет — проверка архитектуры и рендера. Окончательный стиль коллекции,
импорт сторонних пакетов, атласы и реакция на музыку пока не реализованы.

Проверить кадры при 32 и 96 пикселях без запуска окна:
`cargo run -p islandvolt-app --example pet_preview -- <путь-к-preview.png>`.
Столбцы слева направо: покой, моргание, радость, подъём, сон.
