# Встроенные 2D-питомцы IslandVolt

Кот Вольт, лиса Искра и кролик Мята нарисованы для IslandVolt.
Автор кадров и манифестов — IslandVolt contributors. Лицензия [MIT](../../LICENSE).

Пять цветных кадров каждого питомца растеризуются в 144×144 пикселя перед запуском
интерфейса и показываются в размере 42 логических пикселя.

Команда для предпросмотра без окна:

`cargo run -p islandvolt-app --example pet_preview -- <путь-к-preview.png>`

Строки сверху вниз — Вольт, Искра, Мята. Столбцы слева направо — покой, моргание,
радость, прыжок, сон.
