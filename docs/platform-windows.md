# Windows: интеграции и совместимость

Цель пользователя — Windows 10 и 11. Это требование продукта, а не уже проверенная поддержка.
Предложение для первой матрицы: Windows 10 22H2 x64 (19045) и Windows 11 x64.
Точные редакции/сборки Windows 11 и минимальная поддерживаемая Windows 10 уточняются на этапе 0.
ARM64 и 32-битная Windows пока не включены в первую матрицу.

## GPUI: первый технический барьер

В upstream GPUI существует Windows-бэкенд. Совместимость отдельного приложения с нужными
сборками Windows, GPU и особыми свойствами окна острова нужно доказать прототипом.
Не делать вывод о поддержке Windows 10 из одного наличия Windows-бэкенда.
Зафиксировать проверенную версию/commit GPUI, toolchain Rust, SDK и требования к GPU.
Если GPUI не работает на целевой Windows 10, оформить блокер и варианты решения;
не менять стек или список поддерживаемых ОС без обсуждения.

## Карта интеграций

| Возможность | Кандидат API / подход | Что проверить |
| --- | --- | --- |
| Остров | GPUI + изолированный Win32 window adapter | Безрамочность, форма, прозрачность, hit-test |
| Поверх окон | Нативное управление окном | Z-order, fullscreen, фокус, DPI |
| Трей, hotkeys | Win32 shell и hotkey APIs | Жизненный цикл, конфликты комбинаций |
| Музыка | GlobalSystemMediaTransportControlsSessionManager | Несколько сессий, отсутствие метаданных |
| Громкость устройства | Core Audio endpoint volume | Смена устройства, mute, уведомления |
| Громкость приложения | Core Audio audio sessions | Несколько сессий одного процесса |
| Активный источник звука | Сессии, process ID, уровень активности | Тишина, несколько процессов, сопоставление |
| Запись общего звука | WASAPI loopback | Формат, устройства, защищённый контент |
| Запись отдельного процесса | Application Loopback | Недоступно на обычной Windows 10 19045 |
| Скрин/видеозахват | Windows.Graphics.Capture | Окно/экран, разрешения, исключение острова |
| Кодирование видео | Media Foundation или проверенный backend | Кодеки, лицензии, синхронизация аудио |
| OCR | Сменный движок; Windows.Media.Ocr как кандидат | Языки, package identity, альтернатива |
| QR | Декодер изображения в фоне | Несколько кодов, некорректные данные |
| Буфер | Clipboard notifications + чтение форматов | Занятость буфера, дубликаты, ограничения |
| Язык ввода | Foreground window + input layout | IME, чужие процессы, RDP |
| Пипетка | Захваченный кадр + преобразование координат | DPI, HDR, пространство цвета |
| Сеть/Bluetooth/VPN | Отдельные адаптеры статуса и команд | Доступность API, права, тип VPN |
| Питание | Win32 power/session APIs | Политики ОС, доступные режимы, подтверждение |

API и библиотеки в таблице — кандидаты, не окончательные зависимости.
Не нужен весь Windows App SDK только ради UI: основным UI остаётся GPUI.

## Ограничения, которые нельзя скрывать

- Медиаметаданные и команды доступны для приложений, интегрированных с системным медиаконтролем.
  Наличие аудиосессии не означает наличие названия трека или команды next.
- WASAPI loopback устройства записывает общий микс. Это не отдельное приложение.
- Для Application Loopback Microsoft указывает минимум build 20348; целевой Windows 10
  22H2 build 19045 ниже этого порога. Fallback: общий звук с явным выбором пользователя.
- Управление громкостью аудиосессии и маршрутизация приложения на другое устройство —
  разные операции. Для второй не обещаем универсальный стабильный API.
- Windows.Media.Ocr требует package identity для desktop-приложений; для portable-поставки
  выбрать другой движок либо отдельно проверить упаковку с identity.
- Сетевой переключатель не равен выключению Wi-Fi: Ethernet, Wi-Fi и VPN имеют разные команды.
- Управление VPN зависит от типа подключения и клиента; сначала статус и переход в настройки,
  затем поддерживаемые профили/провайдеры.
- Защищённый контент и некоторые окна могут быть недоступны для захвата.
- HDR-пипетка требует определения цветового пространства; не обещать точный HEX без проверки.

## Capability detection

На старте определять сборку ОС и наличие API, а не только строку «Windows 10/11».
Каждая интеграция сообщает доступность, причину отказа и fallback.
Пример: «Запись выбранного приложения недоступна; можно записать общий звук устройства».
Не подменять источник записи незаметно, особенно при включённой облачной обработке.

## Обязательные проверки этапа 0

- Чистая сборка и запуск минимального GPUI-окна на обеих целевых ОС.
- Прозрачные углы, скругление, тень, hit-test и отсутствие невидимой области перехвата кликов.
- Показ без кражи фокуса и раскрытие с намеренным фокусом клавиатуры.
- Z-order, трей, глобальная клавиша, закрытие и восстановление.
- DPI, несколько экранов, отключение экрана, sleep/resume, fullscreen.
- Сессии медиаплеера и браузера, системная громкость и громкость приложения.
- COM/WinRT threading и корректная отписка без зависаний на выходе.
- Замер CPU/GPU/RAM в покое и при анимации; численные бюджеты назначить по результатам.
