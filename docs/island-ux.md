# Поведение острова

Детали ниже — базовое предложение для прототипа; визуальный стиль ещё не утверждён.
Предпочтительны собственные пропорции и характер Inslandio с привычной компактной формой.

## Независимые оси состояния

Не смешивать размер, задачу и закрепление в один enum со всеми комбинациями.

| Ось | Значения |
| --- | --- |
| Представление | compact, expanded, hidden |
| Взаимодействие | idle, hover, dragging, keyboard_focus |
| Текущая карточка | часы, музыка, громкость, инструмент и т. д. |
| Удержание | автоматически / закреплён раскрытым |
| Позиция | свободная / заблокированная |
| Видимость | обычная / всегда поверх других окон |
| Режим движения | полный / уменьшенный |

«Закрепить» в первом прототипе предлагает постоянную видимость; удержание раскрытия
и блокировка позиции доступны отдельно, чтобы не связывать три разных поведения.

## Основные сценарии

- В покое: время, ненавязчивая текущая активность и питомец.
- Клик: раскрыть текущую карточку; повторное закрытие/ESC возвращает компактный вид.
- Наведение: короткое превью без перехвата клавиатурного фокуса.
- Горячая клавиша: раскрыть с фокусом; после закрытия вернуть фокус предыдущему окну.
- Перетаскивание: перемещать за выделенную область; кнопки не запускают drag.
- Трей: показать/скрыть остров, открыть настройки, завершить приложение.
- Полноэкранное приложение: предложенное поведение — скрытие, кроме явно закреплённого режима.
- Отключённый монитор: перенести на доступный, не оставлять окно за границами экрана.

## Арбитраж событий

Остров не должен прыгать между карточками при одновременной музыке, копировании и таймере.

| Приоритет | Событие | Поведение |
| --- | --- | --- |
| 1 | Явно открытый инструмент или подтверждение | Удерживать текущий контекст |
| 2 | Активная запись/диктовка | Постоянный индикатор и доступная остановка |
| 3 | Сработавший таймер / важная ошибка | Превью, ожидание реакции |
| 4 | Громкость / язык / копирование | Короткое объединяемое уведомление |
| 5 | Музыка / часы / питомец | Фоновое представление |

Задание пользователя сохраняет контекст; новые события попадают в очередь/индикаторы.
Равные приоритеты обслуживаются по порядку, с дедупликацией по типу и источнику.
Предлагаемый TTL коротких уведомлений — 2 секунды; значения проверяются прототипом.
Истёкшие события не проигрываются после возвращения к острову.
Повторная регулировка громкости обновляет одно превью и продлевает его TTL.
Активный захват не прячется за уведомлением о копировании.

## Контент и приватность

- Копирование: иконка/тип и обрезанное превью по настройке; режим «только факт копирования».
- Пипетка: увеличенный фрагмент, цветовой квадратик, HEX/RGB, явная команда копирования.
- Язык: раскладка именно активного окна; не путать с языком интерфейса Windows.
- Музыка: явный выбор управляемой медиасессии при нескольких источниках.
- Запись/микрофон: видимый статус и кнопка остановки на всём протяжении задачи.
- Питомец не перекрывает текст, slider громкости и критические действия.

## Тема и доступность

Светлая, тёмная и системная тема. Токены цвета, размеров, скруглений и движения едины.
Контрастный текст, понятные подписи, работа с клавиатуры, видимый фокус.
Отключаемые декоративные анимации и реакция на системное уменьшенное движение.
Проверить поведение на масштабировании 100/125/150/200% и разных DPI мониторов.
Для смешанного DPI позиция хранится относительно выбранного монитора в логических координатах.
