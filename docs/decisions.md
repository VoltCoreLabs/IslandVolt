## Технические выводы, требующие проверки в приложении

- Windows-бэкенд GPUI есть; совместимость выбранной версии с нашей матрицей не проверена.
- Контроль аудиосессии, метаданные песни и распознавание песни — независимые возможности.
- Application Loopback имеет более высокий порог сборки, чем Windows 10 22H2.
- Windows.Media.Ocr требует package identity; portable-стратегия должна это учитывать.
- Поведение прозрачного окна, его формы и фокуса — обязательный прототип до MVP.

Ссылки на первичные источники и ограничения находятся в `platform-windows.md`.

## Реализованные решения прототипа

- 2026-11-15: для первого глобального сочетания выбрано Ctrl+Alt+Space.
  Регистрация через закреплённый `global-hotkey` 0.10.0 на потоке Windows message loop;
  библиотека использует RegisterHotKey с подавлением автоповтора. Канал ограничен одним событием.
  Регистрация принадлежит единственной оболочке и освобождается при её удалении.
  Диспетчер библиотеки живёт до выхода процесса и держит только слабую ссылку на канал.
  Клавиатурное раскрытие удерживается отдельно от сохранённого закрепления панели.
  Возврат фокуса допускается только из активного окна острова в ещё существующее окно.
  Нативный тест проверяет конфликт и освобождение комбинации; UI-проверка остаётся открытой.
