# Данные, разрешения и действия ИИ

## Хранение

Предлагается SQLite для структурированных данных и версионированный файл для настроек.
Конкретные Rust-библиотеки выбираются перед реализацией соответствующего слоя.
Репозитории скрывают SQL от фич; изменения схемы идут через миграции.

| Данные | Место / срок |
| --- | --- |
| Настройки, позиция, тема, включённые фичи | Пользовательский конфиг, до изменения |
| Заметки, напоминания, закреплённые приложения | БД, до удаления |
| История буфера | БД, только после включения; срок и лимит настраиваются |
| Изображения буфера, крупные вложения | Файлы с ID в БД, ограничение объёма |
| Чаты ИИ | Локально по настройке; облачная история зависит от провайдера |
| Обложки, погода, загруженные модели | Кеш с лимитом размера и управлением очисткой |
| Скриншоты и видео | Выбранная пользователем папка |
| Ключи API и токены | Защищённое хранилище Windows через отдельный порт |
| Диагностика | Ротация, лимит размера, без содержимого пользовательских данных |

Базовые данные размещать в пользовательских AppData, не рядом с exe.
Portable-режим — отдельное будущее решение; он влияет на OCR и защиту секретов.
Все форматы содержат версию схемы; экспорт заметок не должен зависеть от внутренней БД.

## История буфера

- По умолчанию не вести историю, пока пользователь её явно не включил.
- Предлагаемый начальный лимит: 200 записей / 7 дней; значения ещё не утверждены.
- Дедупликация, поиск, закрепление, очистка одной записи и всей истории.
- Не копировать новый элемент обратно в буфер при его чтении; исключать цикл уведомлений.
- Учитывать доступные маркеры исключения из истории, но не обещать распознавание всех секретов.
- Пауза, исключения приложений и режим «показать копирование без сохранения».
- Защищать данные на диске; способ шифрования проверить вместе с поиском и экспортом.
- Закреплённые записи не очищаются по TTL, но входят в общий настраиваемый лимит объёма.

## Локальные и облачные провайдеры

Общий порт для каждой задачи: ASR, ИИ-чат, перевод, распознавание песни, текст песни, погода.
Не делать один неограниченный «универсальный AI API» на все задачи.
Пользователь выбирает провайдера и режим для конкретной возможности.
Локальная обработка может требовать загрузки модели; размер и лицензия показываются заранее.
При недоступности локальной модели облако не включается молча.
Для облачной операции показывать, какие данные и какому провайдеру будут отправлены.
Сетевые запросы имеют отмену, таймаут и ограниченные повторы; ошибки не блокируют остров.

## Каталог разрешений продукта

Разрешения приложения дополняют, но не заменяют ограничения Windows.

| Capability | Политика по умолчанию |
| --- | --- |
| Читать медиаметаданные и показывать часы | Доступно, отключается в настройках |
| Менять громкость / запускать закреплённое приложение | По явной команде пользователя |
| Микрофон / захват экрана / запись звука | Включение и видимый индикатор активности |
| Сохранять историю буфера | Отдельное включение, пауза и очистка |
| Отправлять текст/аудио/изображения в облако | Выбранный провайдер и явное разрешение |
| Менять сеть, Bluetooth, VPN | Явное действие и проверка доступности |
| Перезагрузка / выключение | Подтверждение с отменой и понятным последствием |

## Системный помощник

ИИ не получает произвольный shell и не обходит разрешения через свободный текст.
Поток: запрос пользователя → план инструментов → проверка схемы и разрешений →
предпросмотр при необходимости → исполнение → результат и журнал метаданных действия.

Для каждого инструмента: ID, входная схема, права, уровень риска, возможность отмены,
предусловия, таймаут и структурированный ответ. Порты повторно проверяют условия перед действием.
Подтверждённые параметры связываются с конкретным действием; модель не меняет их после согласия.
Скриншот, OCR, QR, буфер и страницы — недоверенные данные; текст из них не даёт новых прав.
Содержимое экрана или буфера не прикладывается к чату автоматически.
Сначала инструменты чтения и обратимые команды; питание, удаление и широкая автоматизация позже.

## Напоминания и время

Хранить дедлайн и часовой пояс; работающий таймер использует монотонные часы.
На старте и после resume вычислять просроченные напоминания без массового повторного показа.
Уточнить поведение закрытого приложения: MVP-напоминания не обещают срабатывание без процесса.
Постоянный фоновый процесс или интеграция с планировщиком — отдельное решение этапа 3.

## Восстановление

Миграции выполняются транзакционно с резервной копией перед изменением формата.
Видео пишется так, чтобы авария не уничтожала все уже записанные данные; формат проверить этапом 5.
Очистка кеша не удаляет заметки, экспорт и сохранённые пользователем записи.
Отмена облачного запроса прекращает локальную работу, но не гарантирует удаление уже переданных
данных у провайдера; это ограничение объясняется в настройках облачной обработки.
