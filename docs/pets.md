# Питомцы внутри IslandVolt

Это локальные животные в нашем приложении; интеграция с питомцами ChatGPT не требуется.
Сейчас проектируется формат, ассеты и изображения ещё не создаются.

## Модель

Питомец — пакет данных и графики, а не отдельная реализация поведения в Rust для каждого вида.
Общий проигрыватель анимаций и планировщик реакций обслуживают всю коллекцию.
MVP содержит одного питомца; последующие пакеты подключаются без изменения оболочки острова.
Идеи для коллекции: кот, собака, лиса, кролик, панда, капибара, дракон.
Состав, стиль и первый вид ещё не выбраны.

## Пакет

```text
assets/pets/<pet-id>/
├─ manifest.json       # ID, версия формата, автор, лицензия, превью
├─ animations/         # отдельные небольшие описания анимаций
├─ atlases/            # кадры / атласы
└─ preview.png
```

Точный формат выбирается после проверки рендера GPUI; JSON здесь — предложение.
Манифест не содержит исполняемого кода и внешних URL, выполняемых при загрузке.
Описания анимаций разделяются по состояниям, каждый текстовый файл не длиннее 300 строк.
Графика версионируется отдельно от логики; лицензия указывается для каждого пакета.

## Метаданные

- ID пакета, версия схемы, имя и локализуемое описание.
- Авторство, лицензия и источник ассетов.
- Размер кадра, масштаб, прозрачность, якорь относительно поверхности острова.
- Набор анимаций, длительности кадров, повтор и допустимость прерывания.
- Состояние покоя и fallback при отсутствии необязательной анимации.
- Границы отрисовки: питомец не перекрывает важные элементы карточки.

## Состояния и реакции

| Состояние | Триггер | MVP |
| --- | --- | --- |
| idle | Нет активности | Да |
| blink | Нерегулярное моргание | Да |
| sleep | Длительный простой / уменьшенное движение | Да |
| happy | Клик по питомцу или успешное действие | Да |
| listen | Диктовка / активный микрофон | Позже |
| music | Воспроизведение музыки | Позже |
| thinking | Ожидание ИИ | Позже |
| notify | Таймер или событие | Позже |
| move | Смена позиции в пределах острова | Позже |

Названия состояний — предметные; количество кадров и переходы зависят от пакета.
Реакция на музыку сначала привязана к состоянию play/pause, без обещания синхронизации с битом.
Необязательная анимация заменяется idle. Повреждённый пакет отключается с объяснением.

## Производительность и настройки

Предлагаемый диапазон кадров анимации 12–24 fps, уточнить по стилю и измерениям.
Обновление логики питомца не должно перерисовывать весь остров без необходимости.
Текстуры кешируются с лимитом памяти, выгружаются при смене пакета.
В скрытом состоянии проигрывание остановлено; на батарее доступна экономия.
Уменьшенное движение — статичный кадр или редкие простые реакции.
Настройки: выбрать питомца, скрыть, масштаб, интенсивность реакций.
Одновременно активен один питомец в MVP; несколько одновременно — отдельная будущая возможность.

## Приёмка пакета

- Правильный manifest и поддерживаемая версия, безопасные относительные пути.
- Ограничены размеры файлов, текстур, количество кадров и объём распакованного пакета.
- Есть idle и корректный preview, все ссылки на кадры разрешаются.
- На светлом и тёмном фоне нет ореолов; якорь не прыгает между кадрами.
- Пакет работает при смене DPI и отключении декоративных анимаций.
- Лицензия позволяет выбранный способ распространения приложения.
